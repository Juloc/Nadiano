# Known limitations — 0.1.0-alpha.1

- This is an internal household pre-release. Database and content compatibility may still change before Beta.
- MIDI practice targets current stable desktop Chrome and Edge. Runtime capability checks remain authoritative.
- Real-device validation requires a human test matrix: five complete sessions across at least two supported browsers and one digital piano. Automated fake-MIDI tests cannot replace this evidence.
- The review indicator uses the first lesson-defined interval after the latest successful work. Full spaced-review scheduling is planned for WP-027.
- Ear-training reference audio is available, but the interactive ear-training answer engine is planned for WP-025.
- MusicXML import, PWA/offline guarantees, generated exercises and public accounts are outside Alpha scope.
- MIDI cannot verify posture, tension, movement quality or which finger was used. These remain explicit self-assessments.
- Backup is a documented cold-volume procedure. There is no in-app backup/restore workflow yet.
- Mobile MIDI practice and non-Chromium browser support are not validated for this Alpha.
