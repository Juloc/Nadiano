# Nadiano 1.0.4

Nadiano 1.0.4 delivers the learner-focused UI redesign on top of the stable 1.0 learning and MIDI engine.

## Learner navigation and daily flow

- the normal learner interface now has five primary destinations: Today, Learn, Songs, Train and Progress;
- Today uses the existing learner progress service to show due reviews, the recommended next lesson and real course completion instead of static placeholder content;
- secondary setup, profile, language and settings actions no longer compete with the main learning navigation;
- phone navigation uses the same five destinations with consistent accessible SVG icons.

## Practice workspace

- notation now dominates the focused practice workspace on tablet and desktop;
- essential mode, tempo, hand, loop, zoom, start/stop and MIDI controls remain reachable without a long vertical form;
- fullscreen, reference playback and metronome controls are grouped as secondary practice tools;
- live feedback is quieter and the score cursor follows the current/problem location;
- results surface the first problematic measures and a concrete next action before detailed metrics;
- leaving practice returns to Learn for lessons and Songs for repertoire/private imports.

## Songs and training surfaces

- bundled Nadiano repertoire and private MusicXML/MXL imports now share one Songs library and the same practice route;
- Songs can be filtered by text, source and readiness state;
- Learn, Train and Progress have distinct learner-facing purposes instead of equal-weight technical cards.

## MIDI setup

- MIDI onboarding is now a progressive five-step flow: browser check, permission, device selection, key/pedal test and completion;
- the setup test confirms distinct played keys and separately detects sustain (CC64), sostenuto (CC66) and soft/una-corda (CC67) when present;
- raw MIDI diagnostics remain available behind a secondary disclosure instead of dominating onboarding;
- device disconnect/reselection keeps the setup flow recoverable.

## Quality

- German and Indonesian learner flows remain paired;
- existing reduced-motion, keyboard focus and accessibility checks are preserved;
- frontend build/lint/tests, .NET tests, Chromium critical path, content validation, vulnerability checks and Docker/Trivy verification remain release gates.
