# Nadiano 1.0.0

Nadiano 1.0 is the first supported stable self-hosted release.

## Learning

- complete beginner path from F0 through F1, B1 and B2 to selected E1 foundations;
- 110 guided bilingual lessons and 220 deterministic exercises;
- 15 listening lessons, 10 repertoire tasks and five stage assessments;
- daily session planning, delayed review and explainable recommendations;
- note reading, rhythm, articulation, dynamics, basic sustain pedal, coordination and practice strategy.

## Practice and content

- Web MIDI practice with pitch, timing and duration feedback;
- wait, loop, hands-separate, performance, rhythm, listen-and-copy and tempo-ladder modes;
- MusicXML and MXL import into a profile-private library;
- part, voice, hand and fingering controls;
- installable PWA shell and idempotent offline result queue;
- separate diagnostics for sustain, sostenuto and soft pedal.

## Data and operations

- separate local learner profiles;
- complete profile export including learning evidence, review queue and private library metadata;
- documented cold backup, restore, upgrade and rollback procedure;
- non-root read-only container with dropped Linux capabilities;
- immutable version and commit image tags plus `latest`;
- container vulnerability scan and browser verification before release.

## Upgrade

Back up the complete Nadiano data directory before changing the image from `0.2.0-beta.1` to `1.0.0`. The application applies committed database migrations before reporting ready. See `docs/UPGRADE_TO_1.0.md` and `docs/BACKUP_AND_RESTORE.md`.
