# Nadiano 0.1.0-alpha.1

First internal household Alpha of the complete foundation learning loop.

## Included

- separate local learner profiles with isolated preferences and progress;
- German and Indonesian interface and lesson content;
- MIDI capability setup, device selection and sanitized diagnostics;
- F0 foundation lessons and selected F1 learning path;
- 20 original exercises, 4 listening tasks and 3 original mini-pieces;
- generated expected-event data and deterministic pitch/onset scoring;
- lesson prerequisites, completion and next-lesson recommendation;
- progress page with recent attempts, completion coverage, competency distribution, cautious category trends and due-review indicators;
- application/database/content version endpoint at `/api/diagnostics/version`;
- Docker Compose deployment and documented cold backup/restore procedure.

## Container tags

- `ghcr.io/juloc/nadiano:0.1.0-alpha.1`
- `ghcr.io/juloc/nadiano:sha-<commit>`

## Verification

CI builds and tests the .NET solution and frontend, validates all bundled content, builds the container and scans it for high/critical known vulnerabilities. The remaining real-piano matrix is documented in `docs/ALPHA_RELEASE_CHECKLIST.md` and cannot be replaced by automation.

See `docs/KNOWN_LIMITATIONS_ALPHA.md` before deployment.
