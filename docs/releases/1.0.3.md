# Nadiano 1.0.3

Nadiano 1.0.3 closes the remaining software-enforceable accessibility and modest-hardware performance gates from the 1.0 roadmap.

## Accessibility hardening

- the Chromium release path now checks the core learner pages for duplicate IDs, a main landmark, exactly one page heading, positive tabindex values, image alternatives, labelled form controls and named actions;
- keyboard focus is verified to enter a normal interactive control on the training page;
- the check covers Home, Setup, Learn, 1.0 Training, Private Library and Progress;
- these automated checks are a WCAG-focused baseline and do not replace the roadmap's manual keyboard review with real browsers and assistive settings.

## Modest-hardware performance gate

- the stable image is now started with one CPU and 512 MiB RAM before publication;
- startup must reach readiness within 30 seconds;
- Home, Setup, Learn and 1.0 Training are warmed and sampled ten times each with a 1.5-second p95 ceiling;
- readiness checks have a 500 ms p95 ceiling;
- measurements are published as `performance-profile.json` with every stable release.

All 1.0.2 learning content, practice modes, imports, PWA behavior, profile isolation, backup/restore/rollback rehearsals, vulnerability scanning and license reporting remain unchanged.
