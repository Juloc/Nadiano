# Nadiano 1.0.1

Nadiano 1.0.1 is the corrected stable 1.0 release.

## Correction

- backup and restore documentation now targets the actual persistent container path `/data` and the supplied named volume;
- documented production port is aligned with the Compose file (`18200`);
- the release upgrade rehearsal now mounts the Beta and stable containers to the same real `/data` volume;
- the rehearsal creates a Beta profile and verifies that the same profile is still exportable after the stable image starts;
- all 1.0.0 learning, practice, import, profile and PWA functionality remains unchanged.

Deploy `ghcr.io/juloc/nadiano:1.0.1` for the stable 1.0 line.
