# Nadiano 0.2.0-beta.1

Nadiano Beta completes the planned B1 and B2 functional scope on the existing modular-monolith architecture.

## Added

- deterministic seeded reading and rhythm cards;
- 45 bilingual guided Beta lessons and 100 reproducible exercises;
- sequential B1/B2 course map with explicit prerequisites and stage checks;
- rhythm tapping with keyboard or pointer input;
- ear-direction exercises with Web Audio reference tones;
- profile-isolated evidence and delayed review queue;
- explainable daily session planning;
- adaptive hands-separate, section, rhythm and tempo recommendations;
- MusicXML and MXL import with size, archive, path and XML security limits;
- private profile library with title, section and target-tempo editing;
- imported scores in the same notation, MIDI and scoring workspace as bundled lessons;
- PWA manifest and public app-shell caching;
- IndexedDB queue for idempotent practice-result delivery after network interruption;
- explicit three-pedal diagnostics for CC64, CC66 and CC67;
- rhythm, hands-separate, loop, tempo-ladder, listen-and-copy and performance modes;
- reduced-motion, keyboard focus and minimum control-size accessibility baseline.

## Data and upgrade

The application applies the committed SQLite migration at startup. Existing Alpha profiles, lessons, attempts and progress remain in place. New evidence, review and private-library tables are profile-bound and cascade when a profile is deleted.

Create a cold backup of the `/data` volume before upgrading. Private imported scores are stored below `/data/private-library` and are not added to the public service-worker cache.

## Verification still requiring real devices

The automated suite covers deterministic generation, content quantities, build, browser path, image scan and persistence behavior. Final Beta hardware sign-off still requires Chrome and Edge with a real USB-MIDI piano, all available pedals and a disconnect/reconnect cycle.
